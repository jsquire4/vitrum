### Added

- **T2.H1 — Real Schied 2017 SVGF denoiser mode `'svgf-real'`** (`@vitrum/shared-denoisers` + `@vitrum/walkaround-hybrid`): implements the full spatiotemporal variance-guided filter from Schied et al. 2017 as a new `denoiser: 'svgf-real'` option alongside the existing `'atrous-variance'` mode. Three new WGSL compute kernels: `svgfReprojection.wgsl.ts` (Eq. 1–4: bilinear 4-tap gather of prev-frame colour + moments, per-tap depth/normal/objId disocclusion rejection, per-pixel history-length increment or reset, EMA α=max(α_min, 1/(h+1))), `svgfVarianceFromMoments.wgsl.ts` (Eq. 5: `Var = max(0, M2 - M1²)` for h ≥ 4), `svgf7x7SpatialFallback.wgsl.ts` (7×7 box-filter spatial luminance variance for h < 4, pass-through otherwise). Host pipeline `svgfRealWebGPU.ts`: reprojection → variance-from-moments → 7×7 fallback → à-trous wavelet filter ×5 (reuses `ATROUS_VARIANCE_WGSL`). GPU memory budget at 1080p: historyLength r16uint ≈4 MB, momentsHistory rg32float ≈16 MB, prevRadiance rgba16float ≈16 MB, motionVec rgba16float ≈16 MB (~52 MB total persistent). Ping-pong texture pairs (A/B) used for historyLength, moments, and prevRadiance to avoid WebGPU read-write hazards. `WalkaroundGPUPipeline` gains `_svgfPingPong` counter and `_svgfReprojUboRef`. `FrameResources` gains 8 new persistent textures. `@vitrum/core` `EngineOptions.denoiser` and `HybridEngineOptions.denoiser` unions updated to include `'svgf-real'`. New exports: `SVGF_REPROJECTION_WGSL`, `SVGF_VARIANCE_FROM_MOMENTS_WGSL`, `SVGF_7X7_SPATIAL_FALLBACK_WGSL`, workgroup size constants, `SVGFReprojUniforms`, `packSVGFReprojUniforms`, `SVGF_REPROJ_DEFAULT_UNIFORMS`, CPU emulation functions (`svgfReprojCPU`, `svgfVarianceFromMomentsCPU`, `svgf7x7FallbackCPU`), `runSVGFRealWebGPU`. Tests: 9 test groups in `__tests__/svgfReal.test.ts` covering identity reprojection, convergence, disocclusion reset, object-ID mismatch, variance-from-moments Eq. 5, 7×7 spatial fallback, end-to-end 50-frame convergence, WGSL export content, and `packSVGFReprojUniforms` round-trip.

- **T2.H4 — Full Veach §10.3 BDPT MIS** (`packages/shared-samplers/src/bdptMIS.ts`): implements `buildBDPTStrategyPDFs_full` + `bdptConnectionMIS_full` + `geometricTermG` and the `BDPTFullVertex` interface. `buildBDPTStrategyPDFs_full` performs the complete Veach Algorithm 10.4 recursive-ratio sweep — O(k) enumeration of all k+1 strategy PDFs for a BDPT path of length k (PBR4e Eq. 16.16). Left sweep: `p_{s−1} = p_s · pdfRev[s] / (pdfFwd[s] · G(v_{s−1}↔v_s))`; right sweep: `p_{s+1} = p_s · pdfFwd[s+1] · G / pdfRev[s+1]`. Specular vertices zero out all strategies whose sweep passes through them (§10.3.5). `geometricTermG` implements `|cos θᵢ · cos θⱼ| / ‖xᵢ − xⱼ‖²` (§8.3.2). Existing `_partial` API retained as deprecated alias — no breaking changes; all 36 prior `bdpt.test.ts` tests continue to pass. New `__tests__/bdptVeachFull.test.ts`: 31 tests across 6 groups (T1 path-length-2 sum-to-1; T2 equal-PDFs 1/N recovery; T3 specular zero-weight; T4 recursive-ratio invariance vs. independent manual accumulation; T5 analytic G formula spot-checks; T6 camera/light endpoint and degenerate-input guards). Tolerances: 10–12 decimal places for ratio invariance; analytic G checks to 12 decimal places.

- **Albedo demodulation in the à-trous indirect chain** (sweep 2026-05-11, Item 24): implements Schied 2017 §4.1 albedo demodulation for the indirect GI channel. `shade.wgsl.ts` now writes the albedo-demodulated lighting signal (`Lo_indirect / albedo`) to `hdrIndirectOut` and the visible-point diffuse albedo to a new `hdrAlbedoOut` texture (binding 14 in the frame BGL). `indirectCombine.wgsl.ts` re-multiplies the denoised lighting by albedo at combine time: `output = direct + filtered_lighting × albedo`. - **`@vitrum/walkaround-hybrid` GTAO Jiménez 2016 slice integral** (sweep 2026-05-11, Item 23): `gtao.wgsl.ts` replaces the simplified Bavoil-style HBAO formula `(h1+h2)/π` with the full Jiménez 2016 §4.2 Eq. 11 closed-form slice integral, verified against Intel XeGTAO.hlsli. Per slice: surface normal is decoded from the G-buffer and projected onto the slice plane to derive γ (the signed projected-normal angle from the view axis); horizon angles are clamped to ±π/2 around γ to restrict integration to the upper hemisphere relative to the surface normal; each side's contribution is `(cos(γ) + 2·h·sin(γ) − cos(2·h − γ)) / 4`; the per-slice result is weighted by `projNormalLen` before averaging over slices. New `gtaoSliceIntegral(h, n, cosN)` helper. Multi-bounce (Jiménez §5.2) deferred — albedo G-buffer not wired into GTAO pass. 12 new tests added to `sprint15-gtao.test.ts`: 4 structural shader-string checks + 8 analytical CPU-mirror tests of the slice integral.

- **`@vitrum/walkaround-hybrid` RC octahedral solid-angle normalization** (sweep 2026-05-11, Item 22): replaced uniform `4π/N` Monte-Carlo normalization in `walkaroundDiffuseLighting.ts` with per-bin solid-angle weights `Ω_i` from a precomputed `computeOctahedralSolidAngles(gridSize)` lookup (new `rc/octahedralSolidAngles.ts`). The octahedral grid is not solid-angle-uniform — bins near fold edges subtend ~15% less solid angle than central bins at N=4. The receiver irradiance integral `E = Σ L_i · cos(θ_i) · Ω_i` now uses per-bin `Ω_i` rather than the constant average. Formula: per-bin solid angle computed numerically by decoding the four corner directions and summing the two-triangle spherical quad area (`(‖d1‖ + ‖d2‖)/2`), subdivided 16×16 per cell for < 0.05% error. Reference: Cigolle et al. 2014, JCGT §A.2.
- **`@vitrum/walkaround-hybrid` RC merge integral weighted by actual solid-angle** (sweep 2026-05-11, Item 21, Path A): the `cascadeMerge.wgsl.ts` kernel previously averaged 4 children with equal weight (`÷4`), which is correct only when each parent bin covers exactly 4× the child solid angle (Sannikov paper assumption). The current `CASCADE_DIMS` use non-Sannikov scaling (~2.7–7.2× probe-count ratio, not the paper's /8; ~2.5–3× interval ratio, not ×4) so the ÷4 assumption violated energy conservation across cascade levels. Fix: new `octCellSolidAngle(cx, cy, N)` WGSL helper computes per-bin solid angle inline using the octahedral corner-decode approach; merge is now `merged = Σ child_i · Ω_i / Σ Ω_i`. The non-Sannikov scaling is now explicitly documented in `cascadePyramid.ts` header. References: Sannikov 2023, §3; Cigolle et al. 2014, JCGT §A.2.

### Changed

- **`@vitrum/pt-webgpu` BVH encoding canonicalized to relative offsets** (Foundations #26 / D10): `buildCpuBvh` now stores `rightChild − nodeIndex` (relative) instead of the absolute right-child node index. The WGSL traversal in `pathTraceBruteforce.wgsl.ts` updated to match (`let rightChild = nodeIdx + node.rightChildOrTriOffset`). Both sides updated atomically — a partial update would silently produce wrong pixels. Encoding now matches `shared-bvh/normalizeBvhInteriorOffsets` and walkaround-hybrid's `common.wgsl` convention. Dev/test mode: post-build invariant check (`1 ≤ offset < totalNodes` per interior node) added inline. `buildCpuBvh.test.ts` extended with relative-offset assertion.
